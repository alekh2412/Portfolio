# Alekh DevOps Portfolio

A responsive, dark DevOps portfolio starter inspired by the reference portfolio's general approach (hero, skills, project cards, resume and contact sections), customized with Alekh's known background and projects.

## Run locally
Open `index.html` in a browser. For best results, use VS Code Live Server.

## Before publishing
1. The supplied resume PDF is included in `assets/` as `Alekh-Chandrashekhar-Chincholkar-resume.pdf` and is embedded in the Resume section.
2. Check the contact email in `index.html` and replace `alekh2412@gmail.com` if needed.
3. Verify every GitHub project URL and update descriptions to match what you can explain in an interview.
4. Update skill indicators to reflect your honest confidence; they are visual only.
5. Publish with GitHub Pages: repository Settings → Pages → deploy from `main` branch / root.

This is an independently written starter inspired by the reference's broad layout, not a pixel-perfect copy of its source code or personal content.
